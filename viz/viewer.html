Watching a smart-contract bug inside logic gates

This is the real circuit the solver searched: a small vault contract compiled to NAND gates. The solver found the attack below without being told what to look for, and the real Solidity contract loses the funds in the same way.

1. The attack the solver found

Three transactions on an empty vault. Someone donates tokens first, so the vault's books are lopsided. The second depositor gets shares at a bargain, and the third depositor pays 16 tokens and receives nothing.

2. One piece, gate by gate

Each shape is a gate. Copper wires carry 1, grey wires carry 0. Change the numbers or click a bit and watch the signal move through. The bug detector is the rule "someone deposited more than 0 and got 0 shares", built only from NAND gates. It starts with the values from transaction 3.

wire = 1 wire = 0 NAND: D shape with a bubble NOT: triangle; on TapeOut it is a NAND with both inputs joined

3. The whole vault circuit

All the gates the solver searched, with the attack running through them. Signals flow left to right; each column is one gate delay. Bright gates output 1, faded gates output 0. Most gates belong to transaction 3 because its bug check depends on everything that happened before.

Hover a gate to see its column and value. The final gate on the right is the bug output, and it reads 1 for this attack.
